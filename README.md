# E-commerce Sales & Customer Analytics Using SQL

## Project Overview

This project focuses on analysing an e-commerce business database using SQL to identify sales trends, understand customer purchasing behaviour, and evaluate product performance.

The goal is to transform raw business data into meaningful insights that can help businesses make better decisions and improve their sales performance.

## Business Objectives

* Analyse overall sales and revenue performance.
* Identify top-performing products and categories.
* Understand customer purchasing behaviour.
* Identify high-value and repeat customers.
* Evaluate order and payment trends.
* Generate actionable business recommendations.

## Tools & Technologies

* Oracle SQL
* SQL Developer
* Microsoft Excel (reporting)
* Power BI (dashboard)

## Database Structure

The database will contain the following tables:

* Customers
* Products
* Categories
* Orders
* Order_Items
* Payments
* Shipping

## Key Business Questions

1. What is the total revenue generated?
2. Which products generate the highest revenue?
3. Which categories perform best?
4. Who are the highest-spending customers?
5. What percentage of customers make repeat purchases?
6. What are the monthly sales trends?
7. What is the average order value?
8. Which products have the highest order volume?

## Project Structure

The repository will be organised into:

* `database/` – Database schema and sample data.
* `sql/` – SQL analysis queries.
* `results/` – Query outputs and screenshots.
* `dashboard/` – Business intelligence dashboard.
* `reports/` – Business insights and recommendations.
